# Fold Lab

Design folded concrete roofs the way Sergio Musmeci did: set a grid in plan, let the bending moments set the depth, and watch the forces.

- **index.html**: the Musmeci Fold Lab, a single web page. Open it in a browser; nothing to install.
- **downloads.html**: the student guides, and the Grasshopper toolkit for Rhino 8 (Windows), in feet.

Designs save in the browser you use. To move a design to another computer or give it to someone, use **Copy link** or **Copy design code** under Share.

Analysis is for design study (one load case, linear elastic), not construction drawings.
